# 2. 심장도관술 확률과 오즈비 (Odds Ratio vs Relative Risk)

## 문제

연구조사 결과 특정 조건하에서 어떤 사람이 심장도관술을 받는 확률은 백인에서는 0.906, 흑인에서는 0.847이었다.

a. 이 연구에 대한 출판물에서 흑인들이 심장도관술을 받을 오즈가 백인들의 오즈의 60%에 해당한다고 보고하였다. 여기서 60%(정확하게는 57%)라는 값을 어떻게 구하였는지 설명하라.

b. 관련된 출판물에 실린 연구에서는 “의사들은 환자가 백인일 때 비해서 흑인일 때 심장도관술을 실시하는 비율이 60%에 불과하다”라고 보고하였다. 이 해석에서 잘못된 점은 무엇인가? 옳은 비율을 제시하여라. (일반대중들을 대상으로 한 결과에서는 오즈비보다 상대위험도를 사용하는 것이 더 적절하다. 이것이 이해하기 더 쉽고 잘못 해석할 가능성을 줄일 수 있다.)

---

## 해설

### 2.1 기본 설정 및 기호 정의

심장도관술(catheterization)을 받을 확률을 $\pi$라고 하자.

- 백인 (White): $\pi_W = 0.906$
- 흑인 (Black): $\pi_B = 0.847$

### 2.2 문항 a. 오즈비(Odds Ratio)의 계산

오즈(Odds)는 사건이 일어날 확률을 일어나지 않을 확률로 나눈 값($\frac{\pi}{1-\pi}$)이다.

1.  **백인의 오즈 ($\text{odds}_W$):**

$$
\text{odds}_W = \frac{\pi_W}{1 - \pi_W} = \frac{0.906}{1 - 0.906} = \frac{0.906}{0.094} \approx 9.6383
$$

2.  **흑인의 오즈 ($\text{odds}_B$):**

$$
\text{odds}_B = \frac{\pi_B}{1 - \pi_B} = \frac{0.847}{1 - 0.847} = \frac{0.847}{0.153} \approx 5.5359
$$

3.  **오즈비 (Odds Ratio, $\theta$):**
    문제에서 "흑인들의 오즈가 백인들의 오즈의 60%"라는 것은 두 오즈의 비율을 의미한다.

$$
\theta = \frac{\text{odds}_B}{\text{odds}_W} = \frac{5.5359}{9.6383} \approx 0.574
$$

**결론:**
계산된 오즈비는 약 **0.574 (57.4%)**이다.
출판물에서 언급한 "60%(정확하게는 57%)"라는 값은 바로 이 **오즈비(Odds Ratio)**를 백분율로 표현한 것이다.

### 2.3 문항 b. 오즈비 해석의 오류와 올바른 측도 (상대위험도)

**잘못된 점:**
보고서의 문구 "시술을 실시하는 **비율**이 60%에 불과하다"는 표현은 독자로 하여금 **확률의 비율(상대위험도)**로 오해하게 만든다. 즉, 백인이 100명 받을 때 흑인은 60명밖에 못 받는 것처럼 들리지만, 실제로는 그렇지 않다.

**오류의 통계적 원인:**
사건 발생 확률 $\pi$가 매우 높은 경우(Common Outcome, $\pi > 0.1$), 오즈비(OR)는 상대위험도(RR)보다 1에서 더 멀어지는 성질이 있다.

- $RR < 1$ 일 때: $OR < RR$ (효과가 과장되어 보임)
- $RR > 1$ 일 때: $OR > RR$ (효과가 과장되어 보임)

본 문제에서는 $\pi$가 약 0.9로 매우 높으므로, $OR(0.57)$과 $RR(0.93)$ 간의 괴리가 매우 크다.

**옳은 비율 (상대위험도, Relative Risk) 계산:**

$$
RR = \frac{\pi_B}{\pi_W} = \frac{0.847}{0.906} \approx 0.935
$$

**옳은 해석:**
흑인이 심장도관술을 받을 확률은 백인의 **93.5%** 수준이다.
즉, 백인에 비해 흑인이 시술을 받을 확률은 약 6.5% 정도 낮을 뿐이다. 이를 "60% 수준이다(40%나 낮다)"라고 표현하는 것은 통계적 수치를 오남용하여 실제 차이를 왜곡하는 것이다.

---

## R Code 및 실습

```r
# 확률 정의
pi_W <- 0.906
pi_B <- 0.847

# 1. 오즈(Odds) 계산
odds_W <- pi_W / (1 - pi_W)
odds_B <- pi_B / (1 - pi_B)

# 2. 오즈비(Odds Ratio) 계산
OR <- odds_B / odds_W

# 3. 상대위험도(Relative Risk) 계산
RR <- pi_B / pi_W

# 결과 출력
cat("백인 오즈 (Odds_W):", round(odds_W, 4), "\n")
cat("흑인 오즈 (Odds_B):", round(odds_B, 4), "\n")
cat("오즈비 (Odds Ratio):", round(OR, 4), "(약", round(OR*100, 1), "%)\n")
cat("상대위험도 (Relative Risk):", round(RR, 4), "(약", round(RR*100, 1), "%)\n")
```

## 심화 학습 (Deep Understanding)

### 1. 로지스틱 회귀분석에서의 시사점
통계학에서 로지스틱 회귀분석(Logistic Regression)을 선호하는 이유는 수학적으로 $\log(\text{Odds})$가 선형 결합(Linear Combination)으로 표현되기 쉽고, $\pi$가 $0 \sim 1$로 제한되는 문제를 해결해주기 때문이다.

$$ \log \left( \frac{\pi}{1-\pi} \right) = \beta_0 + \beta_1 x $$

여기서 $e^{\beta_1}$이 바로 오즈비(OR)가 된다. 연구자는 이 값을 해석할 때, 사건이 흔한 경우(Common outcome)라면 이것이 상대위험도(RR)와 같지 않다는 점을 명심해야 하며, 필요하다면 한계효과(Marginal Effect)를 통해 확률 차이를 직접 제시하는 것이 좋다.

### 2. 과학적 커뮤니케이션의 윤리
연구 결과를 극적으로 보이게 하기 위해 RR 대신 OR을 사용하는 것은 "Bad Science"의 전형적인 예시이다. 특히 의료 통계에서는 환자나 정책 입안자가 실제 위험(Risk)을 정확히 인지하도록 돕는 것이 중요하므로, 해석이 쉬운 RR이나 RD(Risk Difference)를 함께 보고하는 것이 권장된다.
