# 4. Doll & Hill의 폐암 연구 (Case-Control Study)



## 문제



다음 표는 폐암과 흡연의 상관관계를 조사한 초기 연구들 중 하나인 Richard Doll과 A.Bradford Hill의 연구 결과이다. 영국 런던에 있는 20개의 병원에서 전년도에 폐암을 진단받은 환자들에 대해서 흡연 여부를 조사하였다. 각 환자들에 대해서 연구자들은 대조군으로 같은 병원에서 성별이 같고 나이차가 5년 이하인 폐암에 걸리지 않는 환자를 추출하여 흡연여부를 조사하였다. 여기서 흡연자는 적어도 1년 이상 하루에 한 개 피 이상의 담배를 피우는 사람을 말한다.



| 구 분 | 폐암 환자군 (Case) | 대조군 (Control) |

| :--- | :---: | :---: |

| **흡연** | 688 | 650 |

| **비흡연** | 21 | 59 |

| **합계** | 709 | 709 |



a. 반응변수와 설명변수를 정의하라.

b. 이 연구는 어떤 종류의 연구에 속하는지 밝혀라.

c. 흡연자와 비흡연자에서 폐암으로 고통 받는 비율을 비교하는데 이 자료를 사용할 수 있는가? 이유를 설명하여라.

d. 연관성을 요약하고 결과를 어떻게 해석할 수 있는지 설명하라.

## 해설



### 4.1 문항 a. 변수 정의



- **반응변수 (Response Variable, Y):** 폐암 발병 여부 (Case: 폐암 환자 / Control: 대조군)

- **설명변수 (Explanatory Variable, X):** 흡연 여부 (Smoker / Non-smoker)



### 4.2 문항 b. 연구의 종류



이 연구는 **환자-대조군 연구 (Case-Control Study)**이다.

- **이유:** 연구 시점에 이미 질병(폐암)이 발생한 환자군(Case)과 질병이 없는 대조군(Control)을 먼저 선정한 후, 과거의 노출 요인(흡연 여부)을 역추적하여 조사했기 때문이다. 이는 후향적(Retrospective) 연구 설계이다.



### 4.3 문항 c. 폐암 발병 비율 비교 가능 여부



**사용할 수 없다.**



**통계적 이유:**

이 연구 디자인은 **결과 의존적 표집(Outcome-dependent Sampling)**을 따릅니다. 연구자가 임의로 환자군 709명과 대조군 709명을 고정하여 표본을 추출했기 때문에, 표본 내 폐암 비율은 0.5로 고정됩니다. 이는 실제 모집단(일반 인구)에서의 폐암 발병률(Prevalence)과는 무관합니다.

따라서 $P(Y=1|X)$와 같은 절대적 위험(Risk)을 추정할 수 없으며, 결과적으로 비율의 차(Risk Difference)나 상대위험도(Relative Risk)를 직접 계산할 수 없습니다.



### 4.4 문항 d. 연관성 요약 및 해석



환자-대조군 연구에서는 표집 방식에 영향을 받지 않는 **오즈비(Odds Ratio, OR)**를 사용하여 연관성을 요약해야 한다.



**1) 데이터 분할표 (2x2 Table)**



| | Case (폐암) | Control (대조군) |

|---|---|---|

| **Smoker** | $n_{11} = 688$ | $n_{12} = 650$ |

| **Non-smoker** | $n_{21} = 21$ | $n_{22} = 59$ |



**2) 오즈비 계산**



$$

\widehat{OR} = \frac{n_{11} n_{22}}{n_{12} n_{21}} = \frac{688 \times 59}{650 \times 21}

$$



$$

\widehat{OR} = \frac{40592}{13650} \approx 2.974

$$



**3) 결과 해석**

- **해석:** 폐암 환자일 오즈(Odds of being a case)는 흡연자가 비흡연자에 비해 약 **3.0배** 높다.

- **근사적 해석 (Rare Disease Assumption):** 폐암은 일반 인구집단에서 드문 질병이므로, 이 오즈비는 모집단의 상대위험도(Relative Risk)의 근사값으로 볼 수 있다. 즉, "흡연자는 비흡연자에 비해 폐암에 걸릴 위험이 약 3배 높다"고 해석할 수 있다.

## R Code 및 실습



```r

# 데이터 입력 (행렬 형태)

data <- matrix(c(688, 650, 21, 59), nrow = 2, byrow = TRUE)

rownames(data) <- c("Smoker", "Non-smoker")

colnames(data) <- c("Case", "Control")



# 데이터 확인

print(data)



# 오즈비 계산 함수 (Fisher's Exact Test 사용)

result <- fisher.test(data)



# 결과 출력

cat("Estimated Odds Ratio:", result$estimate, "\n")

cat("95% Confidence Interval:", result$conf.int, "\n")

cat("P-value:", result$p.value, "\n")

```

## 심화 학습 (Deep Understanding)



### 1. 오즈비의 불변성 (Invariance of OR)

전향적 연구(Cohort Study)와 후향적 연구(Case-Control Study) 모두에서 오즈비(OR)는 이론적으로 동일한 값(모수 $\theta$)을 추정합니다.

$$

OR = \frac{P(Y=1|X=1)/P(Y=0|X=1)}{P(Y=1|X=0)/P(Y=0|X=0)} = \frac{P(X=1|Y=1)/P(X=0|Y=1)}{P(X=1|Y=0)/P(X=0|Y=0)}

$$

우변은 $Y$(결과)를 조건부로 하여 $X$(원인)의 비율을 비교하는 형태이며, 이는 정확히 환자-대조군 연구의 데이터 구조와 일치합니다. 이것이 환자-대조군 연구가 유효한 과학적 증거가 되는 수학적 기반입니다.



### 2. Doll & Hill 연구의 의의

1950년에 발표된 이 연구는 "담배는 무해하다"는 당시의 통념을 뒤집은 역사적인 연구입니다. 이후 진행된 코호트 연구(British Doctors Study)에서는 흡연 기간과 흡연량에 따라 폐암 사망률이 급격히 증가함(Dose-Response)을 보여주며 인과관계를 확립했습니다. 오즈비 3.0은 초기 결과이며, 헤비 스모커를 대상으로 하면 오즈비는 20~30 이상으로 치솟기도 합니다.
